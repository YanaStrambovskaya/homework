# Чому тут рядковий enum, а не числовий.

## Ми використовуємо рядковий enum, тому що рядкові значення більш читабельні, зрозуміліші та безпечніші, ніж просто числа, що зменшує ймовірність помилок.

# Чи запрацював би цей код, якби ви не написали слово implements? Чому?

````text
Якби ми прибрали implements Searchable, але залишили метод matches, код би працював, але TypeScript не перевіряв би, чи відповідає клас інтерфейсу Searchable. ```


# Що зникло повністю

```text
Після компіляції повністю зникли abstract, protected, типи даних та опис абстрактного методу abstract describe(): string;.
````

# Що залишилось

```text
Залишилося те, що має реальну поведінку під час виконання JavaScript:
- `enum` перетворився на JavaScript-об’єкт;
- клас `LibraryItem` із приватним полем `#status`, конструктором та методами `getStatus()` і `borrow()`.
```

# Чи з'явились рядки, яких ви не писали

```text
Так, є рядки які я не писала. Зокрема створення JavaScript об’єкту var ItemStatus; з `enum`
```
